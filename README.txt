IBS 운용 도우미 v4.3 - 쉬운 UI 버전

파일
- IBS_multi_mode_v4_3_easy_ui.html

중요
- 전략 계산 로직은 v4.2와 동일합니다.
- 기본 IBS와 IBS 추세형의 매수·매도 조건, 무상한 잔금 재계산, 30일 돌파 판정은 변경하지 않았습니다.
- 화면 구성, 설명, 기록 안전기능과 데이터 준비 기능을 개선했습니다.

==================================================
1. 주요 UI 개선
==================================================
1) 현황 화면
- 총 평가자산, 현금, 보유 평가액, 누적수익률을 한눈에 표시
- 현재 매수차수를 1~4차 단계표로 표시
- 현재 상태에서 다음에 무엇을 해야 하는지 쉬운 문장으로 안내
- 추세형 30일 데이터 준비 상태를 진행률로 표시

2) 오늘 계산 화면
- 날짜와 OHLC 입력 영역을 단계별로 정리
- "시가, 고가, 저가, 종가" 한 줄 붙여넣기 기능 추가
- IBS 값을 0~100 게이지로 표시
- 오늘 행동, 판단 이유, 주문예산, 수량을 크게 표시
- 마지막 일별 기록 되돌리기 버튼 추가

3) 현재 사이클 화면
- 전략 모드, 일반/상승사이클, 매수차수를 명확하게 표시
- 현금과 주식의 현재 비중 표시
- 최근 종가, 평균단가, 다음 매수예산, +20% 목표가 표시
- 최근 사이클 거래 최대 8건 표시

4) 기록 화면
- 사이클 승률, 평균수익률, 최고·최악 사이클, 평균기간 표시
- 기본형/추세형/상승사이클 필터 추가
- 수익/손실 필터 추가
- 사이클 상세를 팝업으로 표시

5) 도움말과 화면
- 상단 ? 버튼에 IBS, 쿼터매도, 평가 MDD, 확정 MDD 설명 추가
- 밝은 화면과 어두운 화면 전환 버튼 추가
- 모바일 터치영역과 글자 크기 개선

==================================================
2. 30일 시장데이터 CSV 초기 등록
==================================================
추세형은 오늘을 제외한 직전 30거래일 종가가 필요합니다.

설정 탭에서 다음 헤더가 있는 CSV를 불러올 수 있습니다.
- Date
- Open
- High
- Low
- Close

작동 방식
- 최근 최대 60개 유효 데이터를 날짜순으로 등록
- 계좌자산은 바뀌지 않고 시장데이터만 일별 기록으로 저장
- 거래를 시작하기 전, 보유수량과 거래기록이 없을 때만 사용 가능
- 거래가 없는 날도 기록되므로 30일 돌파 판정에 활용됨

주의
- CSV 초기 등록은 실제 거래를 자동 생성하지 않습니다.
- 거래를 이미 시작한 뒤에는 CSV 초기 등록을 사용할 수 없습니다.

==================================================
3. 마지막 기록 되돌리기
==================================================
- 오늘 탭과 설정 탭에서 사용할 수 있습니다.
- 마지막 일별 기록과 같은 날짜의 거래를 함께 제거합니다.
- 전량매도 기록을 되돌리면 직전 보유상태로 다시 계산됩니다.
- 중요한 수정 전에는 JSON 백업을 권장합니다.

==================================================
4. 전략 로직 - 기본 IBS
==================================================
- 매수: IBS <= 0.25
- 매도: IBS >= 0.75 전량매도
- 비중 선택
  · 균등형 25/25/25/25
  · 초반형 35/30/20/15
- 매도일에는 재매수하지 않음

==================================================
5. 전략 로직 - IBS 추세형
==================================================
매수
- 1~3차: IBS <= 0.25
- 4차: IBS <= 0.15

매수금
- 1차: 사이클 시작자산의 25%
- 2~4차: 현재 현금 / 남은 매수차수
- 쿼터매도 대금을 현재 현금에 포함
- 매수금 상한 없음

상승사이클 판정
- 직전 30개 기록의 최고 종가를 기준선으로 사용
- 오늘 종가가 기준선을 초과하면 돌파모드 활성
- 돌파모드는 최대 30거래일 유지
- 돌파선 아래 10거래일 연속 마감 시 해제
- 보유 중 한 번이라도 돌파모드에 들어가면 해당 사이클은 종료까지 상승사이클
- 전량매도 후 최근 30개 종가 최고값으로 기준선 재설정

매도
A. 일반사이클
- IBS >= 0.75: 전량매도

B. 상승사이클 1·2차 상태
- 종가 < 평단: 매도 없음
- 평단 <= 종가 < 평단 x 1.20: 현재 보유량의 25% 매도
- 종가 >= 평단 x 1.20: 전량매도

C. 상승사이클 3·4차 상태
- IBS >= 0.75: 전량매도

하루 처리
- 매도 조건을 먼저 확인
- 매도일에는 매수하지 않음

6. 기록 호환
==================================================
- 기존 저장 키 ibs2575_complete_v3를 유지합니다.
- v3.x, v4.1, v4.2 JSON 백업을 복원할 수 있습니다.
- 기존 내부 전략키 q2cap30을 유지하므로 이전 추세형 기록과 호환됩니다.
- 업데이트 전 JSON 백업을 권장합니다.

==================================================
7. 권장 사용 순서
==================================================
1. 기존 앱에서 JSON 백업
2. v4.3 HTML 열기
3. 필요하면 JSON 복원
4. 추세형을 처음 시작한다면 설정에서 최근 OHLC CSV 등록
5. 오늘 탭에서 매일 OHLC 입력
6. 계산 후 실제 체결이면 "이대로 체결 기록"
7. 미체결 또는 거래가 없으면 "거래 없이 오늘만 기록"

IBS 운용 도우미 v5.2 PWA
========================

이번 버전 핵심
--------------
1. 전략 신호와 실제 체결을 분리했습니다.
   - OHLC의 종가는 시장 종가로만 사용합니다.
   - 실제 체결가는 별도로 입력할 수 있습니다.

2. "실제 체결 직접 입력" 기능을 추가했습니다.
   - 당일 신호가 매수인데 다른 가격/수량으로 체결한 경우
   - 전일 매수 신호를 놓치고 다음 거래일에 실제 매수한 경우
   - 전략 신호와 다르게 실제로 매수/일부매도/전량매도한 경우
   를 기록할 수 있습니다.

3. 이월 매수 처리
   - 전일 BUY 신호를 "거래 없이 오늘만 기록"했다면 오늘 탭에 미체결 안내가 표시됩니다.
   - 다음 날 OHLC 입력 -> 오늘의 주문 계산 -> 실제 체결 직접 입력
   - 체결 사유에서 "이전 매수신호 이월" 선택
   - 실제 체결가와 실제 수량 입력 후 저장
   - 그날 전략 신호는 그대로 보존되고 실제 거래만 BUY로 기록됩니다.
   - 매수는 현재의 다음 차수를 1회 사용합니다. 5차 매수는 허용하지 않습니다.

4. 기존 날짜에 거래 추가
   - 기록 -> SOXL OHLC 기록
   - 실제 거래가 없는 직접 입력 OHLC 날짜에는 "거래 추가" 버튼이 표시됩니다.
   - 과거 실제 체결을 추가하면 이후 현금/평단/사이클/자산/MDD를 다시 계산합니다.
   - CSV로 가져온 과거 참고 데이터에는 거래를 추가하지 않습니다.

5. 거래 수정 강화
   - 체결일, 수량, 체결단가, 메모 수정 가능
   - 거래 삭제 시 과거 OHLC 전체를 잘라내지 않고 해당 거래만 제거한 뒤 재계산을 시도합니다.
   - 이후 거래가 해당 거래에 의존해 재계산 불가능하면 삭제를 거부합니다.

6. 기록 화면 개선
   - 거래 기록에 전략/수동/이월 출처 표시
   - 매수신호가 있었지만 거래하지 않은 날은 "매수신호 미체결" 표시
   - OHLC 차트에 실제 체결 위치를 점으로 표시
   - 모바일에서 OHLC 표의 날짜/관리 열을 고정해 좌우 스크롤 시 맥락을 유지

GitHub 업데이트
---------------
1. 현재 앱에서 설정 -> JSON 백업을 먼저 받습니다.
2. 이 폴더 안 파일을 GitHub IBS 저장소 최상단에 모두 업로드합니다.
3. 기존 파일은 덮어씁니다.
4. Commit changes 합니다.
5. GitHub Pages 배포가 끝난 뒤 설치된 앱을 완전히 종료하고 다시 실행합니다.
6. 상단에 "v5.2 PWA"가 보이면 업데이트 완료입니다.
7. 이전 버전이 계속 보이면 Chrome에서 https://sychoi0206.github.io/IBS/ 를 열어 새로고침한 후 앱을 다시 실행하세요.

중요한 데이터 호환성
--------------------
- localStorage 키는 기존과 동일하게 유지했습니다.
- v5.0/v5.1 기록은 그대로 이어집니다.
- 새 수동체결 메타데이터는 기존 기록에 영향을 주지 않습니다.
- 업데이트 전 JSON 백업을 권장합니다.

사용 예시
---------
예: 8/6 IBS가 매수영역이었지만 주문을 놓침
1. 8/6은 "거래 없이 오늘만 기록"
2. 8/7 실제로 $110에 8주 매수
3. 8/7 장 종료 후 8/7 OHLC 입력
4. "오늘의 주문 계산"
5. "실제 체결 직접 입력"
6. 실제 거래 = 매수
7. 체결 사유 = 이전 매수신호 이월
8. 실제 체결가 = 110
9. 실제 수량 = 8
10. 저장

결과:
- 8/6의 전략 BUY 신호와 미체결 기록은 남음
- 8/7의 전략 신호도 그대로 남음
- 8/7 실제 거래는 BUY 8주 @ $110로 기록
- 현금/보유수량/평단/차수/자산이 실제 체결 기준으로 계산됨
